# Object-Oriented Programming in Python

## Description
This repository contains laboratory exercises on Object-Oriented Programming (OOP) in Python, covering fundamental concepts such as classes, objects, attributes, and methods. It demonstrates structured programming and problem-solving using OOP principles.

---

## Objectives
- Understand the basic concepts of Object-Oriented Programming
- Create and use classes and objects in Python
- Apply encapsulation and organization of code
- Solve programming problems using OOP techniques

---

## Activities Included
- Class and Object Creation  
- Attribute and Method Implementation  
- Basic OOP Problem-Solving Exercises  

---

## Technologies Used
- Python 3
- Jupyter Notebook (.ipynb)
